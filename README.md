# parsejson

Parse filesystem json paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/parsejson/

## Install / run

```bash
git clone https://github.com/theworker02/parsejson.git
cd parsejson
node src/cli.js
node --test
```
